# v1.0.0 — manuscript reproducibility package

This release provides the audited code, minimized deidentified derived inputs,
canonical outputs, publication figures, and corrected ArtiSynth validation
materials accompanying the mandibular-length and rapid syllable-timing study.

## Included

- participant-clustered empirical model workflows;
- primary-estimand and small-cluster checks;
- speaker-centered Figures 1 and 2 with reproducible figure data;
- table-source data for the retained manuscript tables;
- exploratory read-speech outputs;
- corrected ArtiSynth V2.4 patch and validated Phase C long tables;
- stage-separated environments, commands, hashes, and limitations.

## Scope boundaries

- The human analyses are observational.
- The primary anatomical sample contains 28 speakers.
- The package does not contain raw participant signals or direct identifiers.
- First-principles EMA/audio extraction is not fully reproducible from this
  package because some raw signals, scripts, and historical run records were
  not preserved.
- All 684 corrected simulation cells were feasible through 10 Hz, the highest
  tested frequency; this is not an observed physical maximum.

Analyzed dataset: SWISSUbase/LaRS Version 1.2,
`10.48656/vc7s-pt02` (canonical DOI `10.48656/6y1s-px92`).
