# Version 1.0.1

This release presents the manuscript reproducibility package in a concise public form.
It includes the reported empirical analyses, minimized deidentified derived inputs,
publication figures, table sources, the ArtiSynth model sensitivity code and validated
tables, and stage-specific environment records.

Changes from version 1.0.0 are limited to documentation and figure presentation:

- improved spacing in Figure 1;
- improved legibility of Supplementary Figure 1;
- simplified Supplementary Figure 2;
- removed machine-local paths and local-only documents;
- consolidated public entry points and reproduction instructions.

The scientific data, model specifications, numerical results, and inferential conclusions
are unchanged.
