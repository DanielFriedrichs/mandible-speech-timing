# Prepublication data-availability draft — V13

This is a compliance working draft, not manuscript-ready language.

The human-participant dataset analyzed in this study is available from SWISSUbase/LaRS as *A multimodal speech-production dataset with time-aligned articulography, EEG, audio, and vocal-tract anatomy*. The analyses used Version 1.2 (version-specific DOI `10.48656/vc7s-pt02`; canonical DOI `10.48656/6y1s-px92`).

A clean repository package containing the retained analysis code, deidentified derived model-stage tables, figure data, canonical outputs, corrected ArtiSynth code and validated long tables, and reproducibility documentation has been prepared. As of 2026-07-24, the target public GitHub URL, immutable commit, release tag, and archival DOI have **not** been verified. They must not be reported as available until the author publishes the package and a subsequent live check passes.

The package does not include raw participant signals or direct identifiers. Raw assistant-by-repetition anthropometric readings are unavailable, and first-principles EMA/audio extraction cannot be fully rerun from the packaged evidence; these limitations are documented explicitly.
