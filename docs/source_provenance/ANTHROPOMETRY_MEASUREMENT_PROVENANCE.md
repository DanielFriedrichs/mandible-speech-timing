# Anthropometry provenance

The released anthropometry records contain one finalized left and one finalized right
external condylion-menton (Co-Me) value for each participant. The analysis predictor is
the arithmetic mean of those two side-specific values.

The public package does not contain the underlying assistant-by-repetition caliper readings
or the calculation record used to finalize the side-specific values. It therefore does not
support an independent repeatability coefficient, standard error of measurement, or
measurement-error correction.
