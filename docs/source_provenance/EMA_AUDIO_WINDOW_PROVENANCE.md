# EMA and audio analysis windows

For each DDK trial, the EMA and sweep-aligned audio analysis interval began 0.25 s after
trial onset and extended for at most 6.0 s. The interval ended 0.25 s before the next trial
onset or cue boundary when either occurred earlier. Segments shorter than 2.0 s were
marked unavailable.

The minimized secondary table contains 6,134 trials from 23 speakers. Its analysis windows
have a median duration of 5.267 s and a maximum of 6.0 s; 78 windows shorter than 2.0 s
are marked unavailable.

The model-stage analyses can be reproduced from the included derived table. Complete
raw-to-derived reconstruction is not possible from this package because some raw signals,
the cycle-aggregation script, and complete extraction run records were not retained.
